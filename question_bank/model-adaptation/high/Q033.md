# Q033 · Agentic 模型的 CPT、SFT、RL 三阶段训练流程分别是什么？为什么 SFT 时要 mask 掉 observation tokens？

模型选型与微调 · 高 · `Agentic训练` `三阶段流程` `observation mask` `损失掩码`

> 真题来源：字节跳动 · AI Agent · 三轮技术面+HR面（2-2）（发帖人自述，未核实）

## 背景描述

这是面向做过 Agent 模型训练的候选人的深水题，表面考流程名词，核心考点在 observation mask 的原因。

## 引出的痛点

背得出三阶段名字但说不清 mask 原因——不理解『模型该学的是策略（何时做什么动作），不是复述环境输出』这一训练目标的本质。

## 考点

三阶段各自的目标与数据形态、SFT 损失该算在哪些 token 上、mask 背后的策略学习原理。

## 思考方向与解题思路

先按数据形态讲三阶段，再聚焦 mask：从『损失定义即学习目标』推导出为什么 observation 不计损失。

## 推荐答案

三阶段：CPT 用大量 Agent 轨迹/工具文档做继续预训练灌领域与工具知识；SFT 用高质量示范轨迹做监督微调学行为模式（对应 InstructGPT 的 SFT 阶段）；RL 用奖励信号（人工反馈或任务奖励）优化端到端策略。SFT 时 mask observation 的原因：observation 是环境产生的外部文本，不是模型策略的输出——对它计算损失会教模型『背诵环境』而不是学习『在什么状态下采取什么动作』。

- CPT（继续预训练）：大规模、无严格标注的领域语料（工具文档、历史轨迹、代码），目标补知识与语感，损失算全部 token。
- SFT（监督微调）：高质量示范轨迹（好任务的完整 Thought-Action-Observation 序列），模型学的是示范行为；与指令对齐的 SFT→RLHF 流程同构。
- RL（强化学习）：以任务成功/偏好反馈为奖励，用 PPO 等优化整条轨迹的策略，解决 SFT 只能模仿、无法超越示范的局限。
- mask 原理：SFT 损失只应定义在『模型应当生成的 token』上——Thought、Action 与最终回答；observation 由环境返回，模型控制不了它的内容。
- 不 mask 的危害：损失鼓励模型预测环境输出的分布，稀释策略信号，模型学会复述工具结果而非决策；轨迹中 observation 占比常超一半，不 mask 会严重偏置训练目标。
- 工程对应：训练框架里轨迹序列按来源分段标注 loss_mask，只有模型生成段计损失。

## 进阶理解

### 三阶段的目标与数据形态

CPT 解决『知道』：用工具文档、接口说明、历史执行轨迹等大规模语料继续预训练，把领域词汇与工具用法灌进参数——无严格标注、全部 token 计损失。SFT 解决『会做』：筛选高质量成功轨迹做监督微调，示范『什么状态采取什么动作』；这与对齐领域的经典路径同构——InstructGPT 的流程正是先收集标注者示范做监督微调，再收集输出排序用于人类反馈强化学习，Agentic 场景把『指令』换成了『任务轨迹』。RL 解决『做得更好』：SFT 上限是模仿示范（且受限于示范质量与多样性），RL 以任务奖励（成功率、过程奖励）或偏好反馈为目标优化策略，允许模型发现示范之外的更优路径，也常用于纠正 SFT 阶段学到的次优习惯。AgentTuning 一类工作验证了这条路线的可行性：用多任务 agent 轨迹做指令微调即可显著提升模型的 agent 能力且保持通用能力。

### observation mask：损失定义即学习目标

Agent 轨迹是交错序列：模型的 Thought/Action 与环境的 Observation 交替出现。监督学习的目标是最大化『模型该负责的 token』的条件概率——模型在真实运行时只生成 Thought、Action 与回答，observation 是工具执行后由环境填入的。因此 SFT 训练时：对模型生成段计算损失、对 observation 段置 loss_mask=0。若不 mask：①目标错位——模型被训练去预测环境输出的分布（工具返回的文本千变万化，本质不可预测），梯度浪费在不可能学会的任务上；②信号稀释——轨迹中 observation 常占 token 大头，策略学习信号被复述任务淹没；③行为退化——模型倾向在 Action 位置生成『像工具返回的内容』。这个设计和对齐训练中只对助手回复计损失、不对用户输入计损失是同一条原理：**损失放在哪，模型就学什么**。

**示例**：用 1 万条成功轨迹 SFT 一个客服 Agent 模型。

1. 数据构造：每条轨迹标记分段——user（用户消息）、assistant（Thought/Action/回答）、tool（observation）。
2. 训练配置：loss_mask 仅对 assistant 段为 1；对照实验不做 mask。
3. 结果对比：mask 版在动作选择准确率上显著更高；不 mask 版学会复述工具输出原文，回答冗长且行动犹豫。

观察：一行 loss_mask 的差别，体现的是对『模型职责边界』的理解——这是 agentic 训练与普通文本 SFT 最本质的分野。
