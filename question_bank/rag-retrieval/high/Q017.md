# Q017 · RAG 的完整流程是怎样的？从文档入库到线上检索，Query 改写、切分、召回、重排、注入各环节怎么做、优化过哪些点？

RAG 检索与知识组织 · 高 · `RAG全链路` `Query改写` `召回重排` `上下文注入`

> 真题来源：面经帖自述信息不详（未核实）

## 背景描述

RAG 全链路是 Agent 项目面试的必考叙述题，面试官会要求逐环讲输入输出，并追问每环的优化点与失败模式。

## 引出的痛点

只会背『切分-向量化-检索-生成』四步，说不出每环的工程选项与取舍，等于没有实际维护过 RAG 系统。

## 考点

离线入库链路与在线检索链路两段完整叙述，每环的输入输出、常见选项、可优化点与兜底。

## 思考方向与解题思路

分离线/在线两条链路逐环展开，每环给一句『输入输出』加一句『优化点』，收尾给典型优化优先级。

## 推荐答案

RAG 分两条链路：离线入库（解析→清洗→切分→Embedding→向量库+关键词索引）与在线检索（Query 改写→混合召回→重排→上下文组装→生成+校验）；优化点集中在切分策略、混合召回、重排与注入格式四环，兜底是检索为空时的降级策略。

- 离线链路：文档解析（PDF/表格/OCR）→ 清洗标准化 → 切分（按结构/语义，带 overlap）→ Embedding → 写入向量库并同步元数据与关键词索引。
- 在线链路：Query 预处理（指代消解、口语改写）→ 混合召回（向量+BM25）→ RRF 或加权融合 → Rerank 精排取 TopN → 上下文组装注入 → 生成并做引用与事实校验。
- 切分优化：按文档结构（标题/段落/表格整块）而非死板定长；chunk 大小与 Embedding 模型窗口匹配；元数据（来源、时间、权限）随块入库参与过滤。
- 召回优化：混合检索互补语义与关键词；TopK 不是越大越好，噪声会稀释生成质量；Query 改写注意保留原始意图，改错要能回退。
- 注入优化：按相关性排序拼接、控制总 token、标注来源编号让模型可引用；检索为空时明确告知模型无依据、禁止编造，走兜底话术或人工。
- 评测：分层归因——先测检索（召回率/命中率）再测生成（忠实度/准确性），避免把检索问题误判为模型问题。

## 进阶理解

### 离线入库链路：质量的决定段

『垃圾进垃圾出』在 RAG 上最明显，入库质量决定上限。解析层：PDF 分文本型与扫描型（OCR），表格要保留结构（行列关系转 Markdown 或键值对）而非打散成行；清洗：去页眉页脚、统一编码、处理换行断句；切分：优先按结构边界（标题层级、段落、表格整体），语义切分补充，chunk 间保留 overlap（常见 10-20%）防止关键句被切断在边界；索引：Embedding 写向量库的同时把来源、章节、时间、权限等元数据随块写入，在线检索时元数据过滤（如只搜生效版本）常带来与算法同量级的收益；关键词索引（BM25 分词）同步建，供混合召回。增量更新：文档变更按块 diff 更新而非全量重建，保留版本与有效期字段。

### 在线检索链路：效率与效果的主战场

Query 预处理：多轮对话先做指代消解与省略补全（『那它的价格呢』→补全实体），可选同义改写提升召回；改写有改错原始意图的风险，实践中常将原 query 与改写 query 并行召回再融合。召回：向量（语义泛化）+ BM25（术语、编号、精确匹配）双路，RRF 或加权融合；TopK 召回多一些、给重排留筛选空间。重排：用交叉编码器（Rerank 模型）对召回的几十条精排，取 TopN（常见 3-10）——初筛看相似度，精排看查询-文档的细粒度相关性，两段式兼顾成本与精度。组装注入：按重排分数排序，标注来源编号，控制注入 token 预算；指令中明确『仅依据提供的材料回答，无依据则说明』。生成后校验：引用回溯（答案中的引用是否真在材料里）与关键事实抽检，形成兜底。

### 优化的优先级与常见误区

经验排序：解析与切分质量 > 混合召回与元数据过滤 > 重排 > 换更大的生成模型。常见误区：①只调生成端 Prompt 不修检索，材料错了怎么调都没用——分层评测（检索层召回率、生成层忠实度）先定位问题层；②盲目加大 TopK，噪声块会稀释注意力，生成质量反降；③忽略检索为空的处理，模型在无材料时会编造，必须显式降级；④Query 改写不加保护，改写偏了整条链路跟着错。回答时给出『每环输入输出 + 一个自己踩过的坑』的结构，最能体现真实经验。

**示例**：企业制度问答机器人，员工问『出差住宿标准是多少』，制度文档是 80 页 PDF。

1. 入库：PDF 解析出章节结构，按条款切分并带章节元数据；『差旅费管理办法 第四章』整块保留，同步 BM25 索引。
2. 在线：query 无需改写；混合召回命中第四章条款与两个相关附件；Rerank 把『住宿标准条款』排到首位，取 Top5。
3. 生成：模型依据条款给出金额标准并标注来源章节；引用回溯校验通过。

观察：能答对这道题的关键不在流程图，而在说清每个环节做过的一次具体优化与它带来的指标变化。
