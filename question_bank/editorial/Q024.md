# Q024 · 用 LLM 做裁判（LLM-as-judge）评估输出质量时有哪些系统性偏差？如何控制位置、长度、自增强等偏差与评测污染？

Agent 评测与可靠性 · 中 · `LLM-as-judge` `位置偏差` `长度偏差` `评测校准`

> 真题来源：阿里巴巴 · 大模型 Agent · 三面（发帖人自述，未核实）

## 背景描述

裁判模型是 Agent 评测的主力工具，但对它的偏差没有认知的候选人会把裁判分数当真理，面试官借此考察评测素养。

## 引出的痛点

裁判模型有系统性偏好（偏爱长回答、偏爱自己风格的输出、受选项顺序影响），不校准的裁判分数会系统性误导迭代方向。

## 考点

三类经典偏差的机理与对策、裁判与人工的一致性校准、评测污染与离线在线偏差。

## 思考方向与解题思路

先列偏差清单与对策表，再讲校准方法与裁判的适用边界。

## 推荐答案

LLM 裁判的系统性偏差包括位置偏差（受答案顺序影响）、长度/ verbosity 偏差（偏爱长回答）、自增强偏差（偏爱自家模型输出）以及推理能力受限；对策是交换顺序多评取均值、盲评与要求逐维打分、匿名化模型来源、用人工标注子集校准一致性；同时防评测污染（答案泄漏）与离线-在线分布偏差。

- 位置偏差：成对比较中裁判倾向选特定位置（常是第一个）；对策是 A/B 与 B/A 各评一次，冲突则平局或仲裁。
- 长度偏差：不论实际质量、偏爱更长更详尽的回答；对策是逐维度评分并显式要求『长度不计入』，或对长度做归一化。
- 自增强偏差：裁判偏爱与自己同源的输出风格；对策是匿名化来源、换用异源强模型做裁判、关键结论人工复核。
- 校准：抽人工标注子集算裁判-人一致性（MT-Bench/Chatbot Arena 论文口径：强裁判可达约 80% 以上一致，接近人与人之间的一致水平），不达标先修裁判提示再上线。
- 评测污染：标准答案或评测样本泄漏进提示/微调数据会让分数虚高；评测集与训练物料物理隔离、版本化。
- 离线在线偏差：离线裁判分布与真实用户不一致；用线上隐式信号与人工抽检定期校准裁判阈值。

## 进阶理解

### 偏差的机理与对策

Judging LLM-as-a-Judge（MT-Bench 与 Chatbot Arena 的提出论文）系统研究了这一方法的可用性与局限，明确列出位置偏差（position bias）、冗长偏差（verbosity bias）与自增强偏差（self-enhancement bias），以及裁判推理能力有限的问题，并给出缓解方案。工程落地对照表：成对比较交换顺序双向评、位置敏感场景改用单答案逐维打分（rubric 化）；冗长偏差通过评分维度显式排除长度、或先做事实性/完整性分解再评；自增强偏差通过匿名与异源裁判缓解；裁判推理不足则把复杂样本升级到更强裁判模型或人工。关键是承认裁判是『有偏的近似器』而不是真值——它的分数要和人工一致性一起报告。

### 校准与污染防控

上线一个裁判前必须做一致性校准：抽样人工双标（两人独立），计算裁判-人一致率与分维度相关系数；论文口径下强裁判（如 GPT-4 级）在成对比较上可达到与人类间一致性相当的水平（约 80%+），这是『可用』的参照线，低于该水平先修裁判提示（给评分标准、锚点样例、允许打并列）再谈使用。污染防控：评测集与提示工程/微调物料隔离，评测样本与答案不出现在任何会被模型看到的管道里；裁判自身的提示也要版本化，防止悄悄改动导致分数不可比。离线在线偏差：裁判打分分布会随被评输出的分布漂移而漂移，需定期用线上人工抽检样本重校准裁判阈值，并监控裁判分数与线上用户信号的相关性——相关性消失就是裁判失效的警报。

**示例**：两个版本的报告生成 Agent 用裁判模型做 A/B 评估。

1. 初评：A 先 B 后，裁判 70% 选 A；怀疑位置偏差。
2. 复评：交换顺序 B/A 再评，A 仅 52% 胜出——原差距主要是位置偏差。
3. 校准：抽 60 对人工标注，裁判-人一致率 83%，达可用线；最终结论『两版质量相当，A 略优』并附一致性数字。

观察：没有交换顺序与人工校准的裁判结论是不可引用的——偏差校准本身就是实验设计的一部分。
