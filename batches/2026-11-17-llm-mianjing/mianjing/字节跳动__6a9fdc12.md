- 公司：字节跳动（渠道：未标注，按帖内标记推断） ｜ 岗位：Agent 开发 ｜ 轮次：二面
- 题目 17 条（题目顺序为原帖顺序）

- 1. 你们用的 Agent 框架是什么？ReAct 还是 Plan-and-Execute？
- 2. 你之前做的 Agent 项目用的是什么架构？LangGraph 还是自研？整体是 master+sub Agent 还是 workflow 形式？为什么这么选型？
- 3. 项目中是单 Agent 还是多 Agent 架构？各个子 Agent 的核心任务和分工是什么？
- 4. 多智能体怎么协作？比如一个写代码一个审查
- 5. 首次生成和多轮补充的链路路由是怎么区分和实现的？
- 6. Agent 的记忆怎么搞？长期短期分别怎么存？
- 7. Agent 的 skills 功能原理是什么？你是怎么设计和实现 skills 体系的？
- 8. 你是怎么构建提示词模板的？在上下文工程方面有哪些实践经验？比如有没有做过 to do list 这类优化，为什么它能让模型更聚焦？
- 9. 项目中有没有做过查询改写？多维度的查询改写具体是什么？当改写需要用户补充信息时，你是怎么设计交互和技术实现的？
- 10. 并行化意图识别是什么？为什么要做并行化？你是如何实现的？
- 11. 怎么让模型老老实实调用工具，不瞎编参数？
- 12. 怎么评估 agent 效果好不好？
- 13. Agent 系统的整体效果怎么评估？在没有用户反馈的情况下，如何进行有效的抽检？
- 14. 当出现 Badcase 时，你怎么快速定位到具体是哪个 Agent 环节出了问题？如何判断应该对哪个 Agent 做 SFT 优化？
- 15. Prompt 调优过程中，经常会遇到 "修好一类、坏了另一类" 的问题，你是怎么解决的？
- 16. 工具调用失败、超时了怎么办？
- 17. 开发 agent 时踩过哪些坑？
