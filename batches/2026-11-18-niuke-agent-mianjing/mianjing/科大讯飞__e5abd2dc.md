- 一、整体感受
- 这场面试主要围绕实习项目、Agent工程设计、AI Coding和技术判断展开。面试官会从简历中的具体描述出发，要求我说明个人职责，再给出异常场景，检查方案能否在真实系统里成立。
- 1. 会反复确认个人贡献范围。我介绍实习中个人所做模块后，面试官继续追问，它和其余的事件触发、工作流编排、异步推理、增量落盘是什么关系。
- 2. 关注异常路径和状态管理。例如两次乱序完成、人工审批、超时、取消，以及 Agent 进程重启后如何恢复。
- 3. 不默认多 Agent 一定更好。会追问什么时候应该把几个 Agent 合并，以及拆分究竟带来了什么收益。
- 4. AI Coding 更强调判断和评审。即使 AI 生成的代码和测试都通过，也要判断是否可以合并，尤其检查并发、幂等和一致性风险。
- 5. 希望看到技术判断如何被证据修正。最后让我举一个最初相信、后来因为实践而改变的技术观点。
