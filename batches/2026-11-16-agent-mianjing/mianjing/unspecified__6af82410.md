## 正文题面

- 从 10 月中下旬开始投递简历到现在，前前后后面试快 15 家了，大厂、中厂还有初创团队都接触过。中间有整整一个星期，一封面试邀约都没收到，那段时间心里挺慌的😮‍💨
- 简单说下我的情况：普本，没有相关实习经历，报了线上课程跟着老师系统学习，也找了辅导打磨项目，自己落地了两个 Agent 实战项目：一个垂直知识库问答智能体（完成流程联调），一个日程自动规划 Agent（Demo 版本）。几乎每一场 Agent 开发面试，面试官都会揪着项目深挖
- 最让我犯难的是我每次都觉得没答到点子上：
- “用户为什么会选择用你这个 Agent？”
- “对比市面上同类方案，你的差异化在哪？”
- “现在直接调用通用大模型也能实现类似效果，还有必要单独开发这个 Agent 吗？”
- 我也试着给出解释，比如支持专属工具调用、面向特定场景做了适配、会话记忆策略做了优化之类的。但总感觉没办法说服面试官。 我也一直在琢磨，面试官是期待我给出特别惊艳、突破性的思路吗？还是他们心里本身就有一个标准答案？我去看过不少同类 Agent，大多也只是在原有方案上调整提示词、优化工具链路、微调交互逻辑。那为什么我的回答总是差一口气？
- 面得多了慢慢发现，每家公司招 Agent 开发看重的东西差别很大：有的看重你对智能体产品的感知，有的想看你落地开发的工程思考，还有的重点考察评测、问题排查的实操经验。
- 这段时间面试给我的感受就是，Agent 开发对综合能力要求很高，找机会的时候，尽量去匹配和自己优势契合的团队，做 Agent 真的不能闷头写Demo，前期的用户调研、场景论证才是根基，它决定了这个智能体有没有真实价值、会不会有人愿意用。或许是我选的场景本身竞争就很饱和，也可能是前期调研不够扎实，没有抓准不可替代的价值点。
- 总而言之，做这个方向最怕自嗨式开发，也要扛住面试官一连串的质疑。先沉下心落地调研，再动手做方案，才不容易走弯路，后面有好消息了再告诉大家🤗～
