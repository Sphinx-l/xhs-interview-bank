## 正文题面

- 1.你们项目里 Agent 是怎么做任务规划的，怎么选 ReAct 还是 Plan-and-Execute？
- 2.怎么防止大模型不调用工具，直接自己编答案？
- 3.Agent 的会话状态和长期记忆，你是怎么分开管理的？
- 4.多 Agent 有哪些分工方式，怎么防止它们结论冲突、互相打架？
- 5.工具调用报错、接口超时的时候，你是怎么处理的？
- 6.上线之后，你会从哪些地方持续看 Agent 的效果？
- 7.对话越聊越长，上下文不够用，你一般怎么处理？
- 8.你做 Agent 落地的时候，遇到过哪些坑？是怎么处理的？
- 💡碎碎念：不要等到被动选择的时候，才慌忙寻找出路，提前铺路，才能拥有选择的底气。
- 不要死背答案，重点理清落地思路，有自己项目案例会加分很多✨
