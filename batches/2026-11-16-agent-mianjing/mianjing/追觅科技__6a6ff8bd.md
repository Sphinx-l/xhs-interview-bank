## 正文题面

- 面试感受：
- 三面下来确实不水，不是背八股能混过去的。一面就直接往项目里戳，Python Java 两边都要能切换，光会调 LangChain 高层 API 必被问穿。二面 LangGraph 状态机和 harness 那块面试官明显自己踩过坑，答浅了直接冷笑。三面已经开始考你敢不敢拍板做减法，不是看你知不知道 MCP 是啥。算法题不算卷，但都要边写边讲复杂度，卡壳就追问边界。整体偏生产落地，追觅这岗位不像在招模型研究员，是在招能把 Agent 塞进业务系统还扛得住线上的那种人。难是真难，但问得干净，不绕弯子。
